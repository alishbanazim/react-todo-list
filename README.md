# React Todo List

A responsive Todo List application built with **React, JavaScript, Tailwind CSS, and React Icons**.

## Features

* Add tasks
* Prevent duplicate tasks
* Mark tasks as completed
* Line-through completed tasks
* Delete individual tasks
* Clear all tasks
* Live date & time
* Responsive design
* Empty task state

## Tech Stack

* React
* JavaScript
* Tailwind CSS
* React Icons
* Vite

## React Concepts

This project helped me practice:

* `useState`
* `useEffect`
* Event handling
* Controlled inputs
* Form handling
* `map()`
* `filter()`
* `some()`
* Conditional rendering
* State updates
* Effect cleanup with `clearInterval()`
